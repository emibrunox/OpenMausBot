- Echo — Social Media & Distribution Specialist
- Pixel — Website QA & Technical Quality Specialist
- Pulse — Analytics & Growth Performance Specialist

## How to use
1. Open the bot/member configuration for the relevant agent.
2. Find its Skills section and follow the platform's import/create-skill workflow.
3. Import the matching `SKILL.md` file or create a skill with the same contents.
4. Verify the skill is actually attached/enabled for that bot. A file existing in a folder does not automatically install it.
5. Test with the first-mission prompt and review the result before granting publishing or production permissions.

## Important
These are specialist skill instructions, not a replacement for each bot's Identity, Soul, Memory, Routine, or permissions configuration. Keep publishing, scheduling, spending, and production changes behind explicit human approval.
